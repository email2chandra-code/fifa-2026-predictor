WHAT THIS PROJECT DOES
----------------------
Walk-forward Poisson/Dixon-Coles model:
  - Tune on 2018 (development)
  - Confirm on 2022 (confirmation)
  - Forecast 2026 (production)
Best iteration for 2018 Brier tuning: iter 4
Production / 2026 forecast iteration: iter 5 (Dixon-Coles tau + Elo anchor)

ENVIRONMENTS
------------
Presentation (view only):  conda activate base
Training / simulation:     conda activate deeplearning
  (numpy pinned 1.26.4 in deeplearning — see fix_deeplearning_env.ps1)

KEY COMMANDS
------------
Full backtest (2018 + 2022, all iterations):
  python run_backtest.py

2026 production (train + win probs):
  python run_production.py --iteration 5

Group-stage predictions (no retrain):
  python run_group_predictions.py --iteration 5 --simulations 10000

Knockout stage reach probs QF / SF / Final / Win (no retrain):
  python run_stage_probabilities.py --iteration 5 --simulations 10000

Executive HTML report:
  python generate_executive_report.py
